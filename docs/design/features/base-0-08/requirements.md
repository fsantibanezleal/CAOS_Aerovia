# Requirements: Release 0.04.000 on the current base

What this release changes: the routes and the landing, the App on the shell's `CaseWorkbench` with its five groups and Focus mode, the executive view and its illustrations, the documentation pages on their areas, and the contract catalog with readiness. Requirements written before the units and completed after them. The folder is named for the base the release adopts (`task/base-0-08`).

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated.

| ID | Requirement | Gate |
|---|---|---|
