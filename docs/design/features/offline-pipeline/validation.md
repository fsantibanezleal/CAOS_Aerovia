# Adversarial validation: Offline pipeline: creation, acquisition, verification and promotion

For each requirement of [`requirements.md`](requirements.md), the check that tries to break it: what is planted or refuted, and the test that plants it. `scripts/check_sdd.py` fails when a requirement has no row here (or two), when a check is empty, and when a gate names a test that does not exist. A planted test under `tests/adversarial/` copies the files it attacks into a temporary folder, plants one defect, runs the named gate and asserts that it fails. The planted tests of `tests/adversarial/test_offline_pipeline_refuted.py` are written by the planted-defect unit of this release (U10a); until it lands, the guard reports the rows that name a test of that file as missing, and nothing else in this table is pending.

| requirement | adversarial check | gate |
|---|---|---|
| OP-001 | in a copy of `cases.py` a coordinate is drawn from an unseeded generator: two creations differ and the named test must fail | `tests/adversarial/test_offline_pipeline_refuted.py::test_op_001_an_unseeded_case_generator_is_caught` |
| OP-002 | in a copy of `io.py` the writer allows NaN: a document with a NaN resistance is written and the named test must fail | `tests/adversarial/test_offline_pipeline_refuted.py::test_op_002_a_writer_that_allows_nan_is_caught` |
| OP-003 | a copy of the artifact folder with one byte of one file changed to another value of the same size: verification must refuse it and the named tests must fail otherwise | `tests/adversarial/test_offline_pipeline_refuted.py::test_op_003_a_tampered_artifact_of_equal_size_is_caught` |
| OP-004 | in a copy of `io.py` promotion deletes the old folder before it moves the new one: a failure in between loses the accepted catalog and the named tests must fail | `tests/adversarial/test_offline_pipeline_refuted.py::test_op_004_a_promotion_that_deletes_before_it_moves_is_caught` |
