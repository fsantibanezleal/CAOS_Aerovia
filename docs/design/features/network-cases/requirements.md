# Requirements: Network cases: the twelve authored networks and the reader's own

The case library (`data/cases.json`, generated by `data-pipeline/aerovia_pipeline/cases.py`) and the way the App offers it as the cases of the workbench. Written on 2026-10-20 after the code (retroactive).

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated.

| ID | Requirement | Gate |
|---|---|---|
| NC-001 | THE case library SHALL hold twelve networks that each validate against the network schema, with identifiers unique across the library. | `tests/contracts/test_documents.py::test_all_twelve_committed_networks_validate` and `tests/contracts/test_network.py::test_network_ids_are_unique_across_the_library` |
| NC-002 | THE pipeline validator and the schema SHALL agree on every network and on a rule the schema states. | `tests/contracts/test_network.py::test_pipeline_and_schema_agree_on_every_network` and `tests/contracts/test_network.py::test_a_rule_the_schema_states_is_a_rule_the_pipeline_states` |
| NC-003 | THE reference solver SHALL conserve mass and pressure on every authored case, and THE browser library SHALL hold the same twelve cases. | `tests/python/test_model.py::test_all_authored_cases_conserve_mass_and_pressure` and `frontend/src/engine.test.ts::includes the complete twelve-case library` |
| NC-004 | THE sealed-leakage intervention SHALL improve every working target ratio against the open-leakage case it pairs with. | `tests/python/test_model.py::test_leakage_sealing_improves_every_working_target_ratio` |
| NC-005 | THE catalog SHALL list exactly the networks of the library, and THE reference checks SHALL refer only to networks of the catalog. | `tests/contracts/test_catalog.py::test_catalog_matches_its_networks` and `tests/contracts/test_catalog.py::test_reference_checks_refer_to_catalog_networks` |
| NC-006 | WHEN a reader changes the case quickly, THE App SHALL keep all twelve authored cases selectable and solvable. | `frontend/e2e/workbench.spec.ts::all twelve authored cases remain selectable and solvable through rapid case changes` |
