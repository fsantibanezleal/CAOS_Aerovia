# Adversarial validation: Network cases: the twelve authored networks and the reader's own

For each requirement of [`requirements.md`](requirements.md), the check that tries to break it: what is planted or refuted, and the test that plants it. `scripts/check_sdd.py` fails when a requirement has no row here (or two), when a check is empty, and when a gate names a test that does not exist. A planted test under `tests/adversarial/` copies the files it attacks into a temporary folder, plants one defect, runs the named gate and asserts that it fails. The planted tests of `tests/adversarial/test_network_cases_refuted.py` are written by the planted-defect unit of this release (U10a); until it lands, the guard reports the rows that name a test of that file as missing, and nothing else in this table is pending.

| requirement | adversarial check | gate |
|---|---|---|
| NC-001 | a copy of `data/cases.json` with the identifier of one network repeated and one required field removed from another: the named tests must fail | `tests/adversarial/test_network_cases_refuted.py::test_nc_001_a_repeated_identifier_and_a_missing_field_are_caught` |
| NC-002 | a copy of one network with a self-loop airway, a rule one side states: the validator and the schema must agree on refusing it, and the named tests must fail if only one side does | `tests/adversarial/test_network_cases_refuted.py::test_nc_002_a_rule_stated_on_only_one_side_is_caught` |
| NC-003 | a copy of `data/cases.json` with one case removed and one resistance set to a value the reference cannot close: the named tests must fail (local-only: needs node and the installed frontend, which the checks job does not install) | `tests/adversarial/test_network_cases_refuted.py::test_nc_003_a_missing_case_and_an_unclosed_case_are_caught` |
| NC-004 | a copy of the sealed case with the sealed crosscut resistance lowered back to the open value: the improvement vanishes and the named test must fail | `tests/adversarial/test_network_cases_refuted.py::test_nc_004_a_sealed_case_that_equals_the_open_case_is_caught` |
| NC-005 | a copy of the catalog with one network renamed and a reference check naming a network that is not in the catalog: the named tests must fail | `tests/adversarial/test_network_cases_refuted.py::test_nc_005_a_renamed_network_and_a_foreign_reference_check_are_caught` |
| NC-006 | in a copy of `Workbench.tsx` the case list omits the last network: the twelfth case is not selectable and the named journey must fail (local-only: needs node, the installed frontend and a browser, which the checks job does not install) (local-only: the full solve, run at release with AEROVIA_FULL_PLANTS=1) | `tests/adversarial/test_network_cases_refuted.py::test_nc_006_a_case_list_that_omits_a_network_is_caught` |
