# Adversarial validation: Static release: the build, the identity and the deployment

For each requirement of [`requirements.md`](requirements.md), the check that tries to break it: what is planted or refuted, and the test that plants it. `scripts/check_sdd.py` fails when a requirement has no row here (or two), when a check is empty, and when a gate names a test that does not exist. A planted test under `tests/adversarial/` copies the files it attacks into a temporary folder, plants one defect, runs the named gate and asserts that it fails. The planted tests of `tests/adversarial/test_static_release_refuted.py` are written by the planted-defect unit of this release (U10a); until it lands, the guard reports the rows that name a test of that file as missing, and nothing else in this table is pending.

| requirement | adversarial check | gate |
|---|---|---|
| SR-001 | a copy of the manifest with the recorded digest of the catalog changed: the data preparation must stop with a mismatch, and the gate must fail otherwise (local-only: needs node and the installed frontend, which the checks job does not install) | `tests/adversarial/test_static_release_refuted.py::test_sr_001_a_catalog_that_differs_from_its_recorded_digest_is_caught` |
| SR-002 | a copy of the release identity with an unknown field and a commit of the wrong length: the named tests must fail | `tests/adversarial/test_static_release_refuted.py::test_sr_002_a_release_identity_with_an_unknown_field_is_caught` |
| SR-003 | the check run against a local server that serves one file with one byte changed, and against a plain HTTP origin: it must refuse both (local-only: needs node and the installed frontend, which the checks job does not install) | `tests/adversarial/test_static_release_refuted.py::test_sr_003_a_served_file_with_a_changed_byte_is_caught` |
| SR-004 | a copy of `frontend/package.json` with a version that differs from `VERSION`: the guard must exit with a finding that names it | `tests/adversarial/test_static_release_refuted.py::test_sr_004_a_version_stated_twice_and_disagreeing_is_caught` |
| SR-005 | a copy of the repository without `deploy/TARGET`, and one that carries a VPS unit file beside the Pages workflow: the guard must exit with a finding in each | `tests/adversarial/test_static_release_refuted.py::test_sr_005_a_missing_or_mismatched_deploy_target_is_caught` |
| SR-006 | a copy of the repository with an extra tracked checkpoint no row declares, and a declared model grown past 5 MiB: the guard must refuse both | `tests/adversarial/test_static_release_refuted.py::test_sr_006_an_undeclared_and_an_oversized_model_file_are_caught` |
