# Five-level deep mine

ID `deep-five-level`; 58 nodes, 75 airways. Five horizons from approximately −130 to −690 m contain three working circuits each, connected by common shafts and far-end inter-level ramps. The main fan retains the 3600 Pa nominal shutoff curve used by the three-level case.

Inspect the deepest horizon in isolation, then restore the full network to see the shared shafts. Compare its target ratio with upper levels at fixed speed. A deep branch resistance change can affect neighbouring levels through the shared pressure field; use sensitivity and baseline differences to identify that redistribution. Compare with `deep-booster` for a specific second-fan intervention.

The extra depth increases explicitly authored series resistance. Coordinate depth by itself does not add natural ventilation pressure, air-density change or heat; those effects are outside this model.
