# Aerovia

An underground ventilation and energy engineering workbench. Inspect a multi-level network, edit resistances and fan settings, compare airflow targets, and reproduce the calculations locally.

Development in progress. No release or deployed app is claimed yet.

The product uses a constant-density, isothermal network model. Included networks are authored engineering scenarios, not mine surveys. Results are numerical planning calculations, not field validation or direct operational control.

Code and authored data: Apache-2.0. External references retain their original rights.
